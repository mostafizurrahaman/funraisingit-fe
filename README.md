# King Isaac / Fun Raising
## Link:https://funraisingit.com/
A modern, comprehensive fundraising and brand-building platform that connects campaign organizers, supporters, and custom merchandise.

## 🎯 Goal
To provide a unified ecosystem where creators, organizations, and individuals can raise funds not only through direct donations but also by building custom brands and selling branded merchandise.

## 💡 What It Solves
Traditional fundraising platforms often separate direct donations from merchandise sales. This project bridges that gap by allowing users to:
- Build a custom brand and merchandise storefront seamlessly.
- Track campaigns, orders, supporters, and payouts in a unified, intuitive dashboard.
- Deliver a trustable, fast, and completely responsive experience for both mobile and desktop users.

## ✨ Core Features
- **Campaign Creator**: Easily launch, customize, and manage donation-focused campaigns.
- **Brand Builder**: Set up custom brands, product layouts, and pricing for merchandise.
- **Unified Dashboard**: Tracking systems for:
  - Active campaigns and donations.
  - Product sales and customer orders.
  - Supporter engagement and lists.
  - Payment payouts and pricing structures.
- **Secure Authentication**: User portal with Sign Up, Login, Forgot Password flows, OTP verification, and secure state management.

## 🛠️ Technology Stack
- **Framework**: [Next.js 16](https://nextjs.org/) (App Router) & [React 19](https://react.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **State Management**: [Redux Toolkit](https://redux-toolkit.js.org/) & Redux Persist
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **UI Components**: [Radix UI Primitives](https://www.radix-ui.com/) & [Lucide Icons](https://lucide.dev/)
- **Notifications**: React Hot Toast
